# Waveroute.pins

Быстрое и приватное браузерное расширение для Chrome и Firefox, которое скачивает изображения с Pinterest в **оригинальном максимальном HD-качестве** (`/originals/`), позволяет выставлять точный количественный лимит, выгружает `.zip` архивы и копирует ссылки прямо для Figma.

---

## Зачем я это создал

Большинство существующих загрузчиков с Pinterest имеют раздражающие ограничения:
- Они вводят искусственные лимиты скачиваний на бесплатных тарифах или просят подписку.
- Не позволяют указать точное количество картинок, которое вам действительно нужно выгрузить с доски.
- В них нет темной темы или удобной интеграции с Figma.

**Waveroute.pins** решает эти проблемы: лаконичный интерфейс в стиле Pinterest с темной темой, который работает на 100% локально в вашем браузере.

---

## Возможности

- **🎯 Количественный лимит (Limit Control)**: Выбирайте пресеты (10, 25, 50, 100, Все) или вводите любое свое число. Авто-скроллинг останавливается автоматически при достижении цели.
- **🔍 Оригинальное HD-качество**: Автоматически преобразует превью-картинки (`/236x/`, `/474x/`, `/736x/`) в полноразмерный оригинальный вариант (`/originals/`).
- **📦 Скачивание ZIP в 1 клик**: Упаковывает все собранные картинки в `.zip` архив прямо на вашем устройстве без отправки данных на сторонние сервера.
- **📋 Быстрый копир для Figma**: Кнопка скопировать все прямые ссылки на оригиналы в буфер обмена для быстрой вставки в Figma, FigJam или плагины мудбордов.
- **🌙 Темный UI в стиле Pinterest**: Минималистичный адаптивный интерфейс в графитовых и зеленых тонах (`#00c853`) с аккуратными кнопками-пилюлями и переключателем светлой темы.
- **🔒 Полная приватность**: Построено на Manifest V3. Без аналитики, без регистраций и без внешних серверов.

## Установка

### Распакованное расширение (Режим разработчика)

#### Google Chrome / Yandex / Brave / Edge:
1. Скачайте или клонируйте этот репозиторий.
2. Откройте страницу `chrome://extensions/` в браузере.
3. Включите **«Режим разработчика»** в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку с репозиторием.

#### Mozilla Firefox:
1. Откройте страницу `about:debugging#/runtime/this-firefox` в Firefox.
2. Нажмите **«Загрузить временное дополнение...»**
3. Выберите файл `manifest.json` из папки репозитория.

---

## Как пользоваться

1. Откройте любую доску, профиль или страницу поиска Pinterest.
2. Нажмите на иконку **Waveroute.pins** на панели инструментов браузера.
3. Выберите желаемый количественный лимит.
4. Нажмите **Start scan** для авто-скролла и сбора HD-картинок.
5. Нажмите **Download ZIP** для сохранения архива или **Copy for Figma** для копирования ссылок.
